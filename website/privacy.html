隐私政策

版本：1.0 | 生效日期：2026-10-14 | NALIDE 团队（https://nalide.com）

一、引言

本隐私政策适用于 NALIDE Cert Manager 官方网站（https://cert.nalide.com，以下简称"本网站"）。本网站为产品介绍与下载页面，由 NALIDE 团队（https://nalide.com）运营。

本网站为纯静态页面，不收集、不存储、不传输任何个人身份信息。

二、我们收集的信息

2.1 我们不收集的信息

本网站：

  • 不要求注册账号，不收集姓名、邮箱、电话等个人身份信息
  • 不使用 Cookie 追踪用户行为
  • 不内置任何统计、分析、广告 SDK（如 Google Analytics、百度统计）
  • 不记录访问者 IP 地址（服务器访问日志除外，见 2.3）

2.2 本地存储的信息

本网站仅在您的浏览器本地存储以下非个人信息，用于改善浏览体验：

存储项说明
语言偏好您选择的网站语言（简体/繁体/英文），保存在浏览器 localStorage，仅本网站可读取

您可随时通过浏览器设置清除本地存储数据。

2.3 服务器访问日志

与所有网站一样，托管本网站的服务器会自动记录标准的访问日志，包括访问时间、请求的页面、浏览器类型。这些日志仅用于服务器运维与安全防护，不会用于识别个人身份，日志保留不超过 30 天。

三、第三方链接

本网站包含指向第三方的链接：

  • GitHub（下载、源码、问题反馈）：受 GitHub 隐私政策约束
  • X / Twitter（社交媒体图标）：受 X 隐私政策约束

点击这些链接后，您将离开本网站，请阅读相关第三方的隐私政策。

四、未成年人保护

本网站内容为技术产品介绍，不包含不适宜未成年人的内容。我们不会主动收集未成年人个人信息。

五、政策更新

本政策更新时，将在本页面顶部标注新的版本号与生效日期。继续浏览本网站即表示您接受更新后的政策。
