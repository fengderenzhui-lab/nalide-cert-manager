功能特性

为证书全生命周期而设计，从申请到续期到部署，一站式搞定。

ACME 自动签发

支持 Let's Encrypt、ZeroSSL、Google Public CA，HTTP-01 / DNS-01 双验证，泛域名无压力。

订单式管理

每次申请创建订单记录：创建 → 验证中 → 签发成功/失败，全程可追踪，失败原因一目了然。

自动续期

到期前 30 天自动续期，失败自动重试，邮件通知兜底，告别半夜证书过期。

一键部署

本地自动检测 Nginx / Caddy，一键写入证书并重载，可选强制 HTTPS 跳转。

REST API

完整的 HTTP API + Token 认证，脚本调用、面板集成，自动化无障碍。

私钥不出内网

所有密钥、证书保存在本地，不上传至任何第三方服务器。DNS 凭证 AES 加密存储。

三步上手

像宝塔一样简单：填域名 → 点申请 → 自动完成。

安装启动

运行安装脚本，自动配置 systemd 开机自启，终端打印面板地址与初始密码。

申请证书

浏览器打开面板，填域名（空格分隔多域名），选验证方式，点申请证书，实时看进度。

部署续期

一键部署到 Web 服务，开启自动续期与邮件通知，之后完全不用管。

常见问题

和宝塔面板的证书功能有什么区别？

宝塔是服务器管理面板，证书只是其中一个模块。本工具是独立的单二进制程序，不依赖任何面板，可用在任何 Linux 服务器上，且提供 REST API 供自动化调用。

支持泛域名证书吗？

支持。在域名框输入 *.example.com，程序会自动切换到 DNS-01 验证，你只需选择 DNS 服务商并填写 API 密钥。

私钥安全吗？

所有私钥只保存在你的服务器本地，不上传至任何第三方。这是 ACME 协议的基本要求，也是本工具的核心原则。

可以管理在别处买的商业证书吗？

可以。导入外部证书后统一管理到期提醒与部署。本工具不销售证书，只做管理。

是免费的吗？

本工具开源免费。证书由 Let's Encrypt 等 CA 免费签发，无任何费用。
